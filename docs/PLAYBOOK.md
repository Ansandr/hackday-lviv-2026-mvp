# MVP playbook (build window 11:15-17:00 = ~5h45m)
- 11:15-11:45 Read challenge, pick ONE user + ONE pain. One-line pitch.
- 11:45-12:30 Stack, roles (UI / backend+Gemma / demo+pitch), repo skeleton. Book mentor slots early (12:00-16:30, max 2).
- 12:30-15:30 Build the single happy path; hard-code non-core parts. Commit often.
- 15:30-16:30 Polish demo, README, screenshots, backup demo video.
- 16:30-17:00 Freeze features, prepare submission materials. SUBMIT BEFORE 17:00.
- 17:00-17:55 While judged: rehearse a 5-min pitch (problem -> live demo -> how Gemma is used -> next steps) + 2-3 min Q&A.
Tips: Ollama fallback if wifi dies; keep prompts in one file; cache model responses for the demo.
