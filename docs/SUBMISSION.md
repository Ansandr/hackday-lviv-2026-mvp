## ZIP з кодом

Збирати з актуального `main` безпосередньо перед здачею (після заморозки коду ~16:30), без секретів і без чужих слайдів:

```powershell
git fetch origin
git archive --format=zip -o submission/hackday-team14-code.zip origin/main ":!notes/ai-dev-presentation.pptx" ":!notes/photo_2026-10-29_22-30-58.jpg"
```

У ZIP немає `.env`, `.venv`, баз даних: `git archive` бере лише закомічене. Перевірити: `unzip -l submission/hackday-team14-code.zip | grep -i "\.env$"` має бути порожнім.
Поточний ZIP (з коміту `7392441`, 111 файлів, 0,5 МБ) лежить у `submission/`, його треба зібрати заново після останніх комітів.
