# Сценарій відеодемо MVP (2:30–3:00)

Запис екрана зараз, моушн-дизайн накладається після. Колонка «Моушн» описує, що домалювати на монтажі.
Формат 1920×1080, масштаб браузера 125%, курсор з підсвічуванням кліків. Голос за кадром можна записати окремо.

## Підготовка (до запису, 3 хв)

1. `.env` з `GEMINI_API_KEY`; Ollama запущена з `embeddinggemma`.
2. `python -m src.backend.seed --reset` (чистий стан мока).
3. `$env:SUPPORT_RAG_MODE = "atlas"; ./start-support.ps1`, скопіювати код `tenant_a` з консолі.
4. Відкрити http://127.0.0.1:8000, увійти, закрити зайві вкладки, вимкнути сповіщення.
5. Зробити пробний прогін кожного сценарію (хостована Gemma інколи відповідає 500/503, тоді повторити).
6. Записувати кожну сцену окремим кліпом: якщо одна зірветься, перезаписується лише вона.

## Що НЕ показувати

- Консоль із кодом входу, `.env`, ключі API, адресу Atlas.
- Стан помилки 500/503 від хостованої Gemma (перезаписати кліп).
- Сирі JSON-відповіді, якщо вони не потрібні для пояснення.

## Монтаж

- Темп: кожна сцена 25–45 с, очікування відповіді моделі прискорити ×2–×4 з позначкою «⏩».
- Субтитри українською (журі дивиться без звуку), шрифт без засічок, великий кегль.
- Кольори моушну під UI: зелений `#274631` / світлий `#e0e8da`, акцент для «помилок» теплий червоний.
- Експорт MP4 H.264, до 100 МБ. Завантажити на Drive з доступом «Усі, хто має посилання», перевірити в режимі інкогніто. Посилання вставити на слайд «Демо».
